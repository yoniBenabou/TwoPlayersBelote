# Toutes les ouvertures de l'IA

L'IA parle la première : son annonce ne dépend que de ses 8 cartes. Les 10,518,300 mains possibles ont été passées dans le réseau ; chaque main est aussi probable qu'une autre, donc les pourcentages sont exacts (aucun échantillonnage). Annonce retenue : la plus probable pour le réseau, comme sur le site.
